# Site Recipes

This directory contains standalone, modular HTML/CSS/JS building blocks.

## Philosophy

- **Building Blocks, Not a Template:** These snippets are inspirational and modular. You may copy, adapt, customize, restyle, or combine them as needed to reflect the authentic personality of each business.
- **Self-Contained & Lightweight:** No external frameworks, no large dependencies. Clean modern CSS (flexbox, CSS grid, system fonts or self-hosted web fonts) and vanilla JavaScript.
- **Mobile-First:** Every recipe is designed to work seamlessly on a 375px mobile viewport without horizontal scrolling, while adapting cleanly to tablet and desktop screens.
- **Fact-Driven:** Always populate snippets with verified data from `facts.json`. Never insert placeholder text, fake reviews, or unverified claims.

## Available Recipes

1. `hero.html` — Three hero patterns: Split (photo + CTA), Typography/Badge (centered, high-contrast), and Card/Quick-Action.
2. `services.html` — Responsive grid of service offerings with descriptions and optional pricing badges.
3. `menu.html` — Menu list with categories, item descriptions, and cleanly aligned pricing.
4. `gallery.html` — Responsive image gallery grid with aspect-ratio management and captions.
5. `reviews.html` — Customer review quotes strip with star ratings, attribution, and verification badges.
6. `call_bar.html` — Mobile-only sticky bottom bar for instant click-to-call action.
7. `hours.html` — Verified opening hours table with vanilla JS "Open Now" / "Closed" live status indicator.
8. `map.html` — Physical address and direct Google Maps directions block.
9. `json_ld.html` — Schema.org `LocalBusiness` JSON-LD structured data script.
