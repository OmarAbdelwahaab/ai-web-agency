# Visual Reference Screenshots

This folder contains high-quality real-world visual reference screenshots for human owners and AI agents designing bespoke websites.

## Directory Structure

Place 5–10 reference screenshots (`.png`, `.jpg`, `.webp`) in the corresponding category folders:

```
sites-workspace/references/
├── README.md               # This guide
├── food/                   # Bakeries, cafes, diners, pizzerias, food trucks
├── health/                 # Pharmacies, dental clinics, physical therapy, optometry
├── trades/                 # Plumbers, electricians, HVAC, roofing, landscaping
├── retail/                 # Barbershops, hair salons, hardware, boutiques, dry cleaners
└── auto/                   # Auto repair, detailing, body shops, tire stores
```

## Reference Guidelines

When selecting and saving reference screenshots:
1. **Authentic Local Vibe:** Focus on real local businesses that look approachable, professional, and established—avoid corporate templates or generic stock SaaS designs.
2. **Typography & Layout:** Look for thoughtful font pairings, purposeful white space, and clear hierarchy that fits the business category.
3. **Mobile & Desktop:** Ideally capture both a mobile viewport (375px) and desktop viewport (1280px) for key landing pages.
4. **Naming Convention:** Name files descriptively, e.g.:
   - `food/bakery-warm-hero-mobile.png`
   - `trades/plumbing-badge-cta-desktop.png`
   - `retail/barber-dark-minimal-mobile.png`
